# La brouette du jardinier

> Dans le jardin, un jardinier pousse une brouette. Elle est pleine de terre. Lina porte un petit plant de salade. Elle suit le jardinier près de la serre.
>
> Une roue touche une pierre. La brouette penche et le plant glisse entre deux mottes de terre.
>
> Le jardinier ramasse le plant. Lina creuse un trou avec une petite pelle. Elle y pose le plant, puis le jardinier couvre les racines de terre.

## Je prépare ma lecture

Avec l’adulte : pleine · serre · glisse · mottes · racines.

Je relis « entre deux mottes de terre » sans couper le groupe.

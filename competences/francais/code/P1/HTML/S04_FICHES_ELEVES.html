La chorale

La chorale arrive dans la salle. Les filles et les garçons se placent près de la porte. Lina regarde le garçon à la guitare.

Les enfants chantent. Ils regardent Lina. Elle montre une carte avec un soleil. Ils chantent une chanson sur le soleil. Puis elle montre une carte avec un chat.

Les enfants chantent une autre chanson. Ils sourient. La guitare donne la dernière note. La chorale salue, puis les enfants sortent de la salle.

Je prépare ma lecture

Avec l’adulte : se placent · les enfants · sourient · dernière · sortent.

Le crabe près de la grotte

Lina marche sur le sable avec son frère. Près de la grotte, un crabe gris se cache sous une pierre. Le frère de Lina montre la pierre du doigt.

Lina reste sur place. Le crabe sort une patte, puis une autre. Il passe devant la pierre et file vers la mer.

Les enfants regardent le crabe sans le suivre. Une vague arrive sur le sable. Le crabe est déjà loin. Lina et son frère reprennent leur promenade.

# Notes enseignants — Présentation des fiches P1

Les supports élèves suivent désormais la charte de présentation. Les corpus et leur ordre sont conservés. Les indications de passation retirées des fiches sont regroupées ici ; les éléments essentiels sont dans le [guide synthétique](GUIDE_ENSEIGNANT.md) et les inventaires, grilles et références complètes dans le [guide détaillé](GUIDE_ENSEIGNANT_DETAILLE.md). Les sept récits hebdomadaires et les deux récits de passation sont des textes créés pour l’exercice.

Les identifiants du guide désignent toujours les items dans leur ordre de lecture, de gauche à droite puis de haut en bas. Les grilles sont maintenant à trois colonnes : en S04-J4 et S05-J4, sélectionner les **quatre premiers groupes** pour retrouver les deux anciennes lignes de deux groupes ; ne pas augmenter la charge du parcours accompagné.

## S02_FICHES_ELEVES

Avec l’adulte : lis les deux premières lignes, puis relis-les. Lecture autonome : lis le tableau, puis les phrases. Si tu bloques, demande de l’aide.

Choisis une phrase à relire. Fais une pause au point. Les phrases sont créées pour l’exercice.

Lecture accompagnée : premier paragraphe, avec aide. Lecture autonome : texte entier après préparation. La question se traite à l’oral ; elle ne compte pas dans le relevé de code.

Je fais une courte pause à la virgule et une pause au point.

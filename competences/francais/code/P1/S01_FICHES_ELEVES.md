# Le fauteuil de Lina

> Lina est une petite fille. Elle arrive près du fauteuil. Une bille roule sous le fauteuil. Lina se penche et ramasse la bille.
>
> Sur le tapis, une feuille cache une autre bille. Lina regarde la feuille, puis le tapis. Elle trouve la bille.
>
> Le soleil arrive sur le fauteuil. Lina pose la feuille près de la fenêtre. Une abeille vole dehors. Lina reste dans la salle et regarde le soleil.
